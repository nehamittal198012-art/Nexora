# NEXORA 🚀

## AI Interview Preparation Assistant

NEXORA is a web-based interview preparation platform designed to help students prepare for technical interviews in one place.

It brings resume analysis, DSA practice, Core CS preparation, aptitude practice, mock interviews, and progress tracking together in a single platform.

- 📄 Resume Analyzer
- 💻 DSA Practice

- 🧠 Aptitude Practice
- 🎤 AI Mock Interview
- 📊 Progress & Analytics

## 📄 Resume Analyzer

The Resume Analyzer allows users to upload a PDF resume and receive:

- Resume score
- Detected skills
- Recommended skills
- Improvement suggestions

## 🎤 AI Mock Interview

The Mock Interview module provides interview questions based on the selected role and difficulty level.

Users can submit answers and receive:

- Score
- Strength
- Improvement suggestions
- Overall interview performance

## 📊 Progress & Analytics

NEXORA tracks preparation progress across:

- Resume
- DSA
- Core CS
- Aptitude
- Mock Interview

The dashboard provides an overall interview readiness score based on these areas.

## ⚙️ Backend API

NEXORA uses a Node.js and Express.js backend.

### API Endpoints

GET `/api/test`

POST `/api/interview`

POST `/api/resume`

The backend handles interview evaluation and PDF resume processing.

## 🎯 Project Objective

The objective of NEXORA is to provide students with a centralized platform for technical interview preparation instead of using multiple separate resources.
